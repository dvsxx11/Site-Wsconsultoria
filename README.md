# WS Assessoria Comercial

Landing page institucional desenvolvida para a **WS Assessoria Comercial**, empresa especializada em consultoria imobiliária, compra e venda de imóveis e assessoria documental em Timon e Teresina.

## 🌐 Site publicado

[Acessar o site da WS Assessoria Comercial](https://wsassessoriacomercial.netlify.app/)

## 📋 Sobre o projeto

O site foi criado para apresentar a empresa, seus principais serviços e seus canais de atendimento de forma clara e profissional. A página possui layout responsivo e facilita o contato dos clientes por formulário, WhatsApp e Instagram.

## ✨ Funcionalidades

- Apresentação da empresa e de seus diferenciais;
- Exibição dos serviços oferecidos;
- Layout adaptado para computadores, tablets e celulares;
- Menu de navegação entre as seções da página;
- Botões de contato pelo WhatsApp e Instagram;
- Formulário para envio de mensagens por e-mail;
- Mapa integrado com a localização da empresa;
- Links para as redes profissionais do desenvolvedor.

## 🛠️ Tecnologias utilizadas

- HTML5;
- CSS3;
- JavaScript;
- Bootstrap Icons;
- Google Fonts;
- FormSubmit;
- Netlify.

## 📁 Estrutura do projeto

```text
├── css/                 # Estilos da página
├── img/                 # Imagens utilizadas no site
├── js/                  # Scripts e carregamento das seções
├── sections/            # Seções HTML organizadas separadamente
└── index.html           # Página principal
```
